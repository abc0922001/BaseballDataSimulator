# Baseball Data Simulator ⚾📊

**純數學棒球數據模擬器與打線蒙地卡羅實驗室（Pure Mathematical Baseball Lineup & Sabermetrics Simulator）**

本專案是一個專注於**棒球機率模型、棒次最佳化（Lineup Optimization）與進階數據分析**的純前端高速模擬器。不渲染任何多餘的比賽動畫，透過 **Web Worker** 背景執行緒與逐打席、逐壘包的真實棒球規則引擎，在 1～2 秒內即可完成 **30 個完整 MLB 球季（共 72,900 場比賽、約 550 萬打席）** 的蒙地卡羅實驗。

---

## ✨ 核心特色

### 1. 純打線控制變因實驗室 (Controlled Lineup Laboratory)
- **30 隊雙聯盟三區架構**：2 個聯盟（AL / NL）× 3 個分區（東 / 中 / 西）× 5 支球隊 = 30 支球隊。
- **MLB 擬真 162 場例行賽**：每隊固定出賽 162 場（同分區 52 場、同聯盟跨分區 64 場、跨聯盟 46 場；主客各 81 場），9 局平手進入**傳統正規延長賽**（無突破僵局免費跑者）直到分出勝負。
- **全聯盟 DH 制與常數投守背景**：每隊固定 9 名先發打者全勤出賽（無傷病、無代打、不區分守備位置），全聯盟投手與守備皆固定為能力 `50` 的基準常數。
- **單一球隊變因控制**：一次僅調整 **1 支主角球隊**，其餘 29 隊維持全能力 `50` 的基準對照組，確保勝率、分區封王率與外卡晉級率的變化 100% 來自你的打線配置。

### 2. 四維能力與打席三階段隨機檢定 (Three-Stage PA Resolution)
每位打者擁有四項能力（範圍 `0–100`，預設皆為 `50`）：
- **選球（Eye）**：決定第一階段四壞保送（`BB`）機率，並微幅降低被三振率。
- **打擊（Contact）**：決定第二階段擊球接觸率、打數安打率（`AVG`）與三振（`K`）vs. 一般出局（`Out`）比例。
- **長打（Power）**：決定第三階段安打轉化為全壘打（`HR`）與二壘安打（`2B`）的比例（`ISO / SLG`）。
- **速度（Speed）**：全面影響**三個壘包的推進與串聯**：
  - 安打額外進壘（`1B` 時一上三 / 二回本、`2B` 時一回本）
  - 盜壘企圖率與成功率（`SB / CS`，含低速防自殺機制）
  - 少於兩出局一壘有人時避免雙殺打（`GIDP`）
  - 少於兩出局一般出局護送推進（三壘跑者得分、二壘跑者進三壘）與內野安打 / 二三壘安打加成

### 3. 精準基準校準與放大實驗型極值
- **預設全 `50` 自然收斂基準**：
  - 打擊三圍：**`.250 / .320 / .400`**（`AVG / OBP / SLG`），`OPS` **`.720`**
  - 團隊場均得分：**`4.5 分 (R/G)`**（單隊 162 場約 1,350～1,390 安打、175～180 全壘打、700～730 得分）
- **放大實驗型極值（`0` vs `100`）**：將 `0` 與 `100` 的能力效果放大（如 `Contact 100` $\approx .400\text{ AVG}$、`Power 100` $\approx 80\text{ HR}$、`Eye 100` $\approx 25\%\text{ BB}$），使單一棒次變因在 162 場與 30 季模擬中能呈現鮮明的統計效果。

### 4. 兩大核心實驗模式
- **🧪 模式一：自由變因實驗模式（Free Sandbox）**
  - 不限點數，自由測試任意假設（例如：「將長打 100 放在第 1 棒 vs. 放在第 4 棒，模擬 30 季後平均勝率與分區封王率相差多少？」）。
- **⚖️ 模式二：1,800 點固定預算挑戰模式（Fixed Budget Challenge）**
  - 與預設全 50 球隊相同的 **`1,800 點` 全隊共享預算池**（附**「鎖定單人 200 點」**切換開關）。
  - **高能力邊際遞增成本**：`0–80` 為 `1:1` 消耗，`81–100` 每提升 1 點消耗 `2 點預算`（能力 100 需 120 點），防止最佳解無腦退化為極端配點，考驗「巨星集中 vs. 均衡打線」與棒次串聯哲學。

### 5. 完整進階數據與實驗對照工具
- **團隊指標**：勝敗場、實際勝率、**畢氏期望勝率（Pythagorean W-L）**、得失分差、**分區冠軍率（3 席/聯盟）**、**外卡晉級率（3 席/聯盟）**。
- **個人基礎與進階數據排行榜**：`AVG`, `OBP`, `SLG`, `OPS`, `ISO`, `BABIP`, `HR`, `RBI`, `R`, `BB`, `K`, `SB`, `CS`, `GIDP`，以及 **`OPS+`**、**`wOBA`**、**`wRC+`**、逐打席精算的 **`WPA`（勝率貢獻值）**與 **`RE24`（24 狀態情境得分貢獻）**。
- **固定亂數種子（Seed）與 A/B 快照並排比較**：支援鎖定 Seed 消除隨機噪音，並將多次實驗儲存為快照（Snapshot）直接並排檢視 $\Delta\text{Win\%}$ 與 $\Delta\text{R/G}$。
