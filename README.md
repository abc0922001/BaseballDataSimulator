## 💡 專案簡介：為什麼需要這款模擬器？

在傳統棒球電玩或模擬遊戲中，玩家往往需要耗費數十分鐘觀看 3D 動畫或等待逐球運算，難以進行大規模、具統計顯著性的打線實驗。

**Baseball Data Simulator** 捨棄所有視覺動畫，將 100% 運算效能投注於**純數學機率模型與真實棒球規則**：
- 透過 **Web Worker 背景多執行緒**，在現代瀏覽器中僅需 **1～2 秒** 即可完成 **30 個完整球季（共 72,900 場比賽、約 550 萬打席）** 的逐球、逐打席、逐壘包運算。
- 嚴格控制實驗變因：全聯盟 30 隊中，**29 支對照組球隊恆定為全能力 50**，使用者僅調整主角隊的 1～9 棒能力與打序，確保任何勝率與得分變化 **100% 來自打線配置變因**。
- 專門解答棒球數據迷與運籌分析師最關心的核心問題：
  - *「將長打 100 的重砲放在第一棒還是第四棒，對單季勝場與得失分差有何具體影響？」*
  - *「在 1,800 點固定預算下，該組建『三巨星集中型打線』還是『九棒均衡特化打線』？」*
  - *「選球 100 + 速度 100 的極端開路先鋒，能為球隊多創造多少勝率貢獻值（WPA）？」*

## 🌟 核心特色與亮點

### 1. 擬真 162 場 MLB 賽程與正規賽制
- **30 隊雙聯盟 6 分區架構**：美國聯盟（AL）與國家聯盟（NL）各設東、中、西區（每區 5 隊）。
- **完全平衡的主客對稱賽程**：每隊出賽 162 場（同分區 52 場、同聯盟跨分區 64 場、跨聯盟 46 場；主場 81 場、客場 81 場）。
- **九局正規賽與傳統延長賽**：9 局平手進入第 10 局起之傳統延長賽，**無突破僵局免費二壘跑者**，保障進階數據純粹性；純規則主客場制（9 局下領先免攻與再見安打/全壘打）。
- **四階同戰績比序**：戰績相同時，依「直接對戰勝率 $\to$ 同分區勝率 $\to$ 得失分差 $\to$ 總得分」精確選出每聯盟 3 席分區冠軍與 3 席外卡。

### 2. 三階段打席檢定與四維能力模型
每位打者擁有四項能力（`0～100`，基準預設皆為 `50`）：
- **選球（Eye）**：控制第一階段四壞保送（BB）機率，並微幅降低被三振率。
- **打擊（Contact）**：控制第二階段接觸率、期望打擊率（AVG）與三振（K）vs. 一般場內出局比例。
- **長打（Power）**：控制第三階段擊出安打時轉化為全壘打（HR）與長打的比例。
- **速度（Speed）**：主導三個壘包的推進流動（安打額外進壘、盜壘企圖與成功率、少於兩出局避免雙殺 GIDP、一般出局護送推進）。

### 3. 精確基準收斂（全能力 50 自然收斂）
當球員四維能力皆為 `50` 時，長期蒙地卡羅期望值自然收斂至 MLB 現代標準環境：
- **打擊三圍**：`.250 / .320 / .400`（AVG / OBP / SLG），OPS `.720`
- **場均得分**：`~4.40 - 4.50 分 / 場`（單隊 162 場約 175～185 轟）
- **標準化進階數據**：全聯盟平均 `OPS+` 與 `wRC+` 恆為 `100`，`RE24` 總和接近 `0.0`

### 4. 完整進階數據（Sabermetrics）
- **團隊層面**：勝敗場、實際勝率、**畢氏期望勝率（Pythagorean W-L）**、分區封王率（%）、外卡晉級率（%）、總季後賽晉級率（%）。
- **個人層面**：`PA`, `AB`, `H`, `HR`, `RBI`, `R`, `BB`, `K`, `SB`, `CS`, `GIDP`, `AVG`, `OBP`, `SLG`, `OPS`, `ISO`, `BABIP`，以及標準化 **`OPS+`**、**`wOBA`**、**`wRC+`**、**`WAR`（勝場貢獻值）**、逐打席精算的 **`WPA`（勝率貢獻值）** 與 **`RE24`（24 狀態情境得分貢獻）**。

### 5. 權威 WAR（勝場貢獻值）模型
- 結合賽伯計量學權威公式：$\text{WAR} = (\text{wRAA} + \text{wSB} + \text{wGIDP} + \text{RepRuns}) / 10.0$。
- **基準收斂**：全 50 基準打者單季 162 場全勤（約 688 PA）自然收斂至 **`~2.29 WAR`**（合格全職先發打者區間）；第一棒長打 100 頂級打者（85 轟）躍升至 **`8.0 WAR`**。
- **即時預覽與 A/B 對照**：在打線編輯器中直接顯示理論期望 WAR（`WAR ~2.2`），並在排行榜與快照對照表中支援即時排序與差值比對。

## 🎮 實驗室介面操作指南

系統在單一互動視圖中整合了四大核心工作區：

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. 打線配置與點數池工作區 (Lineup Editor & Point Pool)      │
│    - 模式一：自由變因實驗 vs 模式二：1800 點固定預算挑戰     │
│    - 1~9 棒四維滑桿、理論三圍即時預覽、一鍵套用經典預設集   │
├─────────────────────────────────────────────────────────────┤
│ 2. 模擬控制與實驗快照列 (Simulation & Snapshot Controls)    │
│    - 選擇季數 (1/10/30/50/100 季)、固定 Seed、Web Worker 進度│
├─────────────────────────────────────────────────────────────┤
│ 3. 結果分析分頁切換 (Tabs)                                  │
│    ├── [分區戰績與晉級率] (Standings & Playoff Odds)        │
│    ├── [打擊數據排行榜] (Leaderboard: OPS+/wRC+/WAR/WPA/RE24) │
│    └── [A/B 實驗快照並排對照] (Snapshot Comparison)         │
└─────────────────────────────────────────────────────────────┘
```

### 兩大實驗模式
1. **🧪 模式一：自由變因實驗（Free Sandbox）**
   - 不設預算上限，自由調整 1～9 棒數值（如測試單一打者全能力 100）。
2. **⚖️ 模式二：1,800 點固定預算挑戰（Fixed Budget Challenge）**
   - 9 名先發打者共享 1,800 點（等同全隊全 50 基準總預算）。
   - **高能力邊際遞增成本**：能力在 `0～80` 為 1:1 消耗；`81～100` 每級消耗 **2 點預算**（能力 100 需 120 點），防止無腦堆滿單項極端值。
   - 可開啟 **「鎖定單人 200 點」**，強制每位球員在個人 200 點預算內調配偏科屬性。

### A/B 實驗快照並排對照
- 模擬完成後，點擊「儲存為實驗快照」。
- 在「A/B 快照對照」分頁中，選擇基準組與實驗組，即可直觀檢視勝場差（$\Delta W$）、勝率差（$\Delta\text{Win\%}$）、場均得分差（$\Delta\text{R/G}$）與 1～9 棒各棒次進階數據的增減消長。

## 💻 本地安裝與開發指令

本專案採純前端架構，無需任何後端資料庫或伺服器環境。

### 1. 安裝相依套件
```bash
npm install --ignore-scripts
```

### 2. 啟動本機開發伺服器
```bash
npm run dev
```
啟動後於瀏覽器開啟 `http://localhost:5173` 即可操作實驗室介面。

### 3. 執行全量自動化測試（含 30 季統計收斂檢驗）
```bash
npm test -- --run
```

### 4. 靜態型別檢查與生產環境建置
```bash
npm run check
npm run build
```
建置產物存放於 `dist/`，可直接託管至 GitHub Pages 或任何靜態主機。
