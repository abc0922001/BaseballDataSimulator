# Baseball Data Simulator — 系統與數學模型設計文件 (Design Document)

## 1. 專案願景與核心目標 (Overview & Goals)

**Baseball Data Simulator（純數學棒球數據模擬器）** 是一個專為棒球數據實驗設計的高速蒙地卡羅（Monte Carlo）模擬實驗室。系統不渲染任何比賽動畫，將 100% 運算資源集中於逐局、逐打席、逐壘包的真實棒球規則數學模擬，用於探討**打者四維能力配置**與**棒次排列（Lineup Optimization）**對單季（162 場）與多季（如連續 30 季）球隊勝率、分區/外卡晉級率及進階數據（`OPS+`、`wRC+`、`WPA`、`RE24`）的因果影響。

### 1.1 核心設計原則
1. **純打線實驗室（嚴格控制變因）**：
   - 全聯盟採 **DH 指定打擊制**（無投手打擊）。
   - 每支球隊固定 **9 名先發打者**（1～9 棒全勤打滿 162 場，無傷病、無疲勞、無代打代跑、不區分守備位置）。
   - 全聯盟投手與團隊防守皆固定為 **能力值 50 的聯盟標準常數背景**。
   - 一次僅調整**單一目標球隊（主角隊）**，其餘 29 支球隊維持全能力 50 的基準配置，確保任何勝率與數據變化 100% 來自受測打線的變因。
2. **自然隨機對決與精準基準收斂**：
   - 每個打席透過**三階段隨機能力檢定**決定結果，不硬性鎖死單季結算成績。
   - 當所有球員四維能力皆為預設值 `50` 時，長期期望值自然收斂至 **`.250 / .320 / .400`（AVG / OBP / SLG，OPS `.720`）** 與場均得分 **`4.5 分（R/G）`**。
3. **兩大實驗模式**：
   - **模式一（自由變因實驗）**：不限總點數，自由調整主角隊任一棒次之四維能力（例如測試「第一棒長打 100、其餘全 50」模擬 30 季後的勝率提升量 $\Delta$）。
   - **模式二（1,800 點固定預算建隊挑戰）**：在與預設球隊相同的總預算（`1,800 點`）與高能力遞增成本規則下，自由分配能力與棒次，挑戰打造最高勝率球隊。

## 2. 聯盟架構、賽制與分區/外卡規則 (League & Schedule Architecture)

### 2.1 聯盟與分區結構
- **2 個聯盟（Leagues）**：美國聯盟（AL）、國家聯盟（NL）。
- **6 個分區（Divisions）**：每個聯盟各設東區（East）、中區（Central）、西區（West）3 個分區。
- **30 支球隊（Teams）**：每個分區 5 支球隊（預設主角隊位於 `AL East` 第 1 隊，可於介面切換）。

### 2.2 162 場擬真例行賽賽程 (MLB-Style 162-Game Schedule)
每支球隊單季固定出賽 **162 場**（主場 81 場、客場 81 場；全聯盟單季共 `30 × 162 / 2 = 2,430 場`）：
- **同分區對戰（52 場）**：對同分區其餘 4 隊各打 13 場（`4 × 13 = 52 場`）。
- **同聯盟跨分區對戰（64 場）**：對同聯盟另外 2 個分區的 10 支球隊，其中 4 隊打 7 場、6 隊打 6 場（`4 × 7 + 6 × 6 = 64 場`）。
- **跨聯盟對戰（46 場）**：對另一聯盟 15 支球隊，對應分區 1 隊打 4 場、其餘 14 隊各打 3 場（`1 × 4 + 14 × 3 = 46 場`）。

### 2.3 比賽規則、主客場與延長賽
- **九局正規賽**：每局分上下半局（客隊先攻、主隊後攻），每半局 3 出局換邊。
- **純規則主客場（無能力值 Buff）**：
  - 主客場不給予任何能力值加成，避免干擾控制變因。
  - 保留棒球規則天然差異：若 9 局上半結束時主隊領先，9 局下半不需進行；9 局下半或延長賽下半主隊超前比分即刻結束比賽（再見比賽 Walk-off）。
- **傳統正規延長賽**：
  - 9 局結束平手時進入第 10 局起的延長賽，直到某局結束分出勝負（無和局）。
  - **不採用突破僵局制（開局不放二壘免費跑者）**，避免免費跑者汙染打者上壘率、打點與 RE24/WPA 數據。

### 2.4 分區冠軍、外卡與同戰績比序 (Standings & Tiebreakers)
- 每季例行賽結束後（**不進行季後賽淘汰賽**），各聯盟獨立結算：
  - **分區冠軍（Division Champions，每聯盟 3 隊）**：東、中、西三區戰績第一名。
  - **外卡資格（Wild Cards，每聯盟 3 隊）**：該聯盟非分區冠軍之其餘 12 隊中，勝率最高的前 3 名。
- **同戰績比序規則（Tiebreaker Hierarchy）**：
  1. **直接對戰勝率（Head-to-Head Win%）**
  2. **同分區內對戰勝率（Intradivision Win%）**
  3. **整季總得失分差（Run Differential, $R - RA$）**
  4. **整季總得分（Total Runs Scored, $R$）**

## 3. 投打對決數學模型：三階段隨機檢定與放大極值映射 (PA Resolution Model)

每位打者具備四項能力值（範圍 `0–100`，整數，預設值皆為 `50`）：
- **打擊（Contact, $C$）**：控制擊球接觸率、降低三振率並決定打數安打率（AVG）。
- **長打（Power, $P$）**：控制擊出安打時的長打轉化率（全壘打 HR 與二壘安打 2B 比例）。
- **速度（Speed, $S$）**：控制內野安打加成、三壘安打（3B）與二壘安打延伸率、盜壘（SB/CS）、避免雙殺（GIDP）及壘上跑者額外進壘。
- **選球（Eye, $E$）**：控制打席獲得四壞球保送（BB）機率並微幅降低三振率。

### 3.1 簡化打席事件定義
- 打席構成：$\text{PA} = \text{AB} + \text{BB}$（不拆出獨立觸身球 HBP 與高飛犧牲打 SF 欄位）。
- 7 種打席最終結果：`BB`（四壞保送）、`K`（三振）、`Out`（一般場內出局）、`1B`（一壘安打）、`2B`（二壘安打）、`3B`（三壘安打）、`HR`（全壘打）。

### 3.2 雙區間線性插值函數 (Piecewise Linear Mapping Function)
為確保能力值 `50` 精準錨定基準值，且 `0` 與 `100` 呈現放大實驗型極端值，定義通用插值函數 $\text{lerp3}(x, v_0, v_{50}, v_{100})$：

$$\text{lerp3}(x, v_0, v_{50}, v_{100}) = \begin{cases} v_0 + \dfrac{x}{50}(v_{50} - v_0), & 0 \le x \le 50 \\[6pt] v_{50} + \dfrac{x - 50}{50}(v_{100} - v_{50}), & 50 < x \le 100 \end{cases}$$

### 3.3 第一階段：選球檢定（Walk Check — 判定 `BB`）
由打者的 **選球（Eye, $E$）** 決定該打席直接獲得四壞保送的機率 $P(\text{BB})$：

$$P(\text{BB}) = \text{lerp3}(E,\; 0.015,\; 0.09333,\; 0.250)$$

- **數學驗證**：當 $E = 50$ 時，$P(\text{BB}) = \frac{0.320 - 0.250}{1 - 0.250} = 9.333\%$。搭配下階段 $\text{AVG} = .250$，上壘率恆等式為：
  $$\text{OBP}_{50} = 0.09333 + (1 - 0.09333) \times 0.250 = \mathbf{.320}$$
- 極端值：$E = 0$ 時保送率僅 `1.5%`；$E = 100$ 時保送率放大至 `25.0%`（單季約 160+ 次保送）。

### 3.4 第二階段：接觸與安打檢定（Contact & Hit Check — 判定 `Hit` vs `K` vs `Out`）
若第一階段未保送，則該打席計為 1 次打數（`AB`）。

1. **打數安打率 $P(\text{Hit} \mid \text{AB})$（即期望打擊率 AVG）**：
   由 **打擊（Contact, $C$）** 主導，並加上 **速度（Speed, $S$）** 的內野安打修正：
   $$\text{AVG}_{\text{base}}(C) = \text{lerp3}(C,\; 0.120,\; 0.250,\; 0.400)$$
   $$\Delta \text{AVG}_{\text{speed}}(S) = \frac{S - 50}{50} \times 0.015$$
   $$P(\text{Hit} \mid \text{AB}) = \text{clamp}\big(\text{AVG}_{\text{base}}(C) + \Delta \text{AVG}_{\text{speed}}(S),\; 0.080,\; 0.450\big)$$
   - 當 $C = 50, S = 50$ 時，$P(\text{Hit} \mid \text{AB}) = \mathbf{.250}$。
   - 當 $C = 100, S = 50$ 時，打擊率放大至 **`.400`**；若 $S = 100$ 更高達 `.415`。

2. **出局類型切分：三振（`K`）vs. 一般場內出局（`Out`）**：
   若該打數未形成安打（基準機率 $1 - 0.250 = 0.750$），判定該出局為三振的條件機率 $P(\text{K} \mid \text{AB Out})$：
   $$P(\text{K} \mid \text{AB Out}) = \text{clamp}\Big(\text{lerp3}(C,\; 0.550,\; 0.295,\; 0.080) - \frac{E - 50}{50} \times 0.030,\; 0.030,\; 0.650\Big)$$
   - 當 $C = 50, E = 50$ 時，$P(\text{K} \mid \text{PA}) = (1 - 0.09333) \times 0.750 \times 0.295 \approx \mathbf{20.06\%}$（單隊 162 場約 1,230～1,280 K）。
   - 其餘未三振之出局即為 **一般場內出局（`Out`）**，會觸發後續壘間雙殺檢定或護送推進檢定。

### 3.5 第三階段：長打等級檢定（Hit Type Check — 判定 `1B / 2B / 3B / HR`）
當打者確認擊出安打（`Hit`）時，由 **長打（Power, $P$）** 與 **速度（Speed, $S$）** 決定安打落點類別：

1. **全壘打條件機率 $P(\text{HR} \mid \text{Hit})$**：
   $$P(\text{HR} \mid \text{Hit}) = \text{lerp3}(P,\; 0.010,\; 0.128,\; 0.520)$$
   - 當 $P = 50, C = 50$ 時，每支安打有 `12.8%` 為全壘打（占 AB 的 `3.2%`，單隊 162 場約 **175～180 轟**，單人約 **19～20 轟**）。
   - 當 $P = 100, C = 50$ 時，每支安打有 `52.0%` 為全壘打（單人單季約 **80 轟**，SLG 高達 `.680+`）。

2. **三壘安打條件機率 $P(\text{3B} \mid \text{Hit})$**：
   主要由 **速度（Speed, $S$）** 決定（扣除 HR 後分配）：
   $$P(\text{3B} \mid \text{Hit}) = \text{lerp3}(S,\; 0.002,\; 0.016,\; 0.060) \times \frac{1 - P(\text{HR} \mid \text{Hit})}{1 - 0.128}$$

3. **二壘安打條件機率 $P(\text{2B} \mid \text{Hit})$**：
   由 **長打（Power, $P$）**（權重 75%）與 **速度（Speed, $S$）**（權重 25%）共同決定：
   $$P_{\text{raw}}(\text{2B}) = 0.75 \times \text{lerp3}(P,\; 0.080,\; 0.184,\; 0.280) + 0.25 \times \text{lerp3}(S,\; 0.100,\; 0.184,\; 0.260)$$
   $$P(\text{2B} \mid \text{Hit}) = P_{\text{raw}}(\text{2B}) \times \frac{1 - P(\text{HR} \mid \text{Hit}) - P(\text{3B} \mid \text{Hit})}{1 - 0.128 - 0.016}$$

4. **一壘安打條件機率 $P(\text{1B} \mid \text{Hit})$**：
   $$P(\text{1B} \mid \text{Hit}) = 1 - P(\text{HR} \mid \text{Hit}) - P(\text{3B} \mid \text{Hit}) - P(\text{2B} \mid \text{Hit})$$

## 4. 完整跑壘推進、盜壘與出局護送模型 (Baserunning & Productive Outs)

系統完整追蹤一、二、三壘上的跑者實體（含該跑者的 `Speed` 與個人數據歸屬），確保得分（`R`）、打點（`RBI`）、盜壘（`SB/CS`）與 `WPA/RE24` 精確計算。

### 4.1 投打對決前：盜壘檢定（Stolen Base Check — `SB` / `CS`）
每個打席開始前，若壘包符合「一壘有人且二壘空」或「二壘有人且三壘空（少於兩出局）」，依前導跑者之 **速度（Speed, $S_{\text{runner}}$）** 進行盜壘檢定：
- **防自殺保護**：當 $S_{\text{runner}} < 45$ 時，盜壘企圖率設為 `0%`（慢速跑者不盲目自殺盜壘，僅在 $S_{\text{runner}} \ge 45$ 時按比例遞增）。
- **盜二壘企圖率 $P(\text{Attempt}_{2B})$**：
  - $S = 50$：`3.5%` / 機會（單人單季約 8～10 次盜壘嘗試）
  - $S = 100$：`22.0%` / 機會（單人單季約 55～70 次盜壘嘗試）
- **盜二壘成功率 $P(\text{Success}_{2B})$**：
  $$P(\text{Success}_{2B}) = \text{lerp3}(S_{\text{runner}},\; 0.50,\; 0.76,\; 0.90)$$
  - $S = 50$ 時成功率 `76%`（恰處於現代棒球盜壘損益兩平點，不增減額外期望得分）；$S = 100$ 時成功率高達 `90%`，創造顯著正期望得分與得點圈推進。
- **盜三壘**：僅在 $S_{\text{runner}} \ge 65$ 且少於兩出局時發動，企圖率為盜二壘之 `20%`，成功率為 $\text{lerp3}(S_{\text{runner}}, 0.45, 0.70, 0.86)$。
- 若盜壘失敗（`CS`），跑者出局、出局數 `+1`；若因此滿 3 出局，該半局直接結束，當前打者下局首棒重新打擊。

### 4.2 安打時的壘上跑者額外推進 (Extra-Base Advancement on Hits)
- **四壞保送（`BB`）**：強制擠壘推進（一壘有人推二壘；一二壘有人推二三壘；滿壘擠回 1 分）。
- **全壘打（`HR`）**：壘上所有跑者與打者皆回本壘得分。
- **三壘安打（`3B`）**：壘上所有跑者皆回本壘得分，打者上三壘。
- **二壘安打（`2B`）**：
  - 二、三壘跑者必回本壘得分。
  - **一壘跑者能否直接衝回本壘得分**（否則停在三壘），由一壘跑者速度 $S_1$ 決定：
    $$P(\text{1st} \to \text{Home} \mid \text{2B}) = \text{lerp3}(S_1,\; 0.20,\; 0.45,\; 0.80) + (\text{outs} == 2 ? 0.10 : 0)$$
- **一壘安打（`1B`）**：
  - 三壘跑者必回本壘得分。
  - **二壘跑者能否直接衝回本壘得分**（否則停在三壘），由二壘跑者速度 $S_2$ 決定：
    $$P(\text{2nd} \to \text{Home} \mid \text{1B}) = \text{lerp3}(S_2,\; 0.30,\; 0.58,\; 0.88) + (\text{outs} == 2 ? 0.12 : 0)$$
  - **一壘跑者能否衝上三壘**（僅在三壘空出時判定，否則停在二壘），由一壘跑者速度 $S_1$ 決定：
    $$P(\text{1st} \to \text{3rd} \mid \text{1B, 3rd empty}) = \text{lerp3}(S_1,\; 0.10,\; 0.28,\; 0.65)$$

### 4.3 一般場內出局：雙殺打（`GIDP`）與護送推進（Productive Outs）
為解決「三振不會雙殺因此優於一般出局」的數學盲點，當打席結果為 **一般場內出局（`Out`，非三振 `K`）** 且當時出局數 `< 2` 時：

1. **雙殺打檢定（`GIDP`）**：
   - 觸發條件：出局數 `< 2` 且 **一壘有跑者**。
   - 雙殺發生機率由**打者自身的速度 $S_{\text{batter}}$** 決定（速度越快越能跑贏一壘封殺避免雙殺）：
     $$P(\text{GIDP} \mid \text{Out, 1st occupied, outs} < 2) = \text{lerp3}(S_{\text{batter}},\; 0.22,\; 0.11,\; 0.02)$$
   - 若發生雙殺：出局數 `+2`，一壘跑者與打者出局（若此時仍 `< 3` 出局，即原本 `0` 出局變 `2` 出局，原三壘跑者不計打點得分、原二壘跑者推進至三壘）。

2. **一般出局護送推進（Productive Out / 高飛犧牲與滾地推進）**：
   - 若未發生雙殺且出局後出局數仍 `< 3`（即原本 `0` 或 `1` 出局）：
     - **三壘有跑者**：有 $P(\text{3rd} \to \text{Home} \mid \text{Out}) = \text{lerp3}(S_3,\; 0.22,\; 0.32,\; 0.45)$ 的機率護送三壘跑者回本壘得分（計打者 1 分打點 `RBI`）。
     - **二壘有跑者（且三壘空出）**：有 $P(\text{2nd} \to \text{3rd} \mid \text{Out}) = \text{lerp3}(S_2,\; 0.15,\; 0.25,\; 0.40)$ 的機率推進二壘跑者上三壘。

## 5. 兩大實驗模式與 1,800 點遞增成本規則 (Experiment Modes & Point Pool)

### 5.1 控制變因原則
- 全聯盟 30 支球隊中，**29 支對照組球隊**的所有打者（1～9 棒）四維能力恆定為 `50 / 50 / 50 / 50`。
- 使用者僅針對 **1 支主角球隊** 的 1～9 棒進行能力配置與棒次排序。

### 5.2 模式一：自由變因實驗模式 (Free Sandbox Mode)
- 不限制全隊或單人點數預算，四維能力皆可在 `0–100` 間任意指定。
- 內建一鍵快速實驗預設集（Presets）：
  - 「基準全 50 對照組」
  - 「第一棒長打 100（其餘 50）」vs.「第四棒長打 100（其餘 50）」
  - 「第一棒選球 100 + 速度 100（其餘 50）」

### 5.3 模式二：1,800 點固定預算挑戰模式 (Fixed Budget Challenge Mode)
- **總預算池**：全隊 9 名打者共享 **`1,800 點`** 預算池（對應預設 9 人 × 4 項 × 50 點 = 1,800 點）。
- **「鎖定單人 200 點」切換開關**：
  - **關閉時（預設）**：允許跨球員自由挪移點數（例如將中心棒次堆高至 280～320 點，後段棒次壓低至 100 點）。
  - **開啟時**：強制每位球員的四項能力消耗總和不得超過 `200 點`，專注測試單一球員四維偏科與棒次搭配。
- **高能力邊際遞增成本函數 $\text{Cost}(x)$（`81–100` 加重消耗）**：
  - 為防止最佳解無腦退化為極端的 `100` 與 `0`，能力值在 `0–80` 區間採 `1:1` 消耗，`81–100` 區間每提升 1 點能力消耗 **`2 點預算`**：
    $$\text{Cost}(x) = \begin{cases} x, & 0 \le x \le 80 \\[4pt] 80 + 2 \times (x - 80), & 81 \le x \le 100 \end{cases}$$
  - **預算成本對照**：
    - 能力 `0` = 消耗 `0 點`
    - 能力 `50`（預設基準）= 消耗 `50 點`（故預設全 50 球員剛好消耗 `200 點`，全隊剛好 `1,800 點`）
    - 能力 `80` = 消耗 `80 點`
    - 能力 `90` = 消耗 `100 點`
    - 能力 `100` = 消耗 `120 點`

## 6. 基礎數據、進階數據與期望值矩陣演算法 (Sabermetrics & Matrices)

### 6.1 團隊統計指標
- **基礎戰績**：出賽（`G`）、勝場（`W`）、敗場（`L`）、實際勝率（`Win%`）、得分（`R`）、失分（`RA`）、場均得分（`R/G`）、得失分差（`Diff`）。
- **畢氏期望勝率（Pythagorean Expectation）**：
  $$\text{Pyth Win\%} = \frac{R^{1.83}}{R^{1.83} + RA^{1.83}}, \quad \text{Pyth W} = 162 \times \text{Pyth Win\%}$$
  用於消除單季一分差比賽運氣波動，精準檢視打線真實得分創造力。
- **多季蒙地卡羅聚合指標（如模擬 $N = 30$ 季）**：
  - 平均勝場 $\bar{W} \pm \text{SD}$、平均勝率 $\overline{\text{Win\%}}$、95% 信賴區間（CI）、最高/最低單季勝場。
  - **分區封王率（Division Title %）**：$N$ 季中拿到分區第一的百分比。
  - **外卡率（Wild Card %）** 與 **總晉級率（Postseason Berth % = 分區冠軍 + 外卡）**。

### 6.2 個人打擊基礎與比率數據
- 計數數據：`G`, `PA`, `AB`, `R`, `H`, `1B`, `2B`, `3B`, `HR`, `TB`, `RBI`, `BB`, `K`, `SB`, `CS`, `GIDP`。
- 比率數據：
  - $\text{AVG} = \frac{H}{AB}$, $\text{OBP} = \frac{H + BB}{PA}$, $\text{SLG} = \frac{TB}{AB}$, $\text{OPS} = \text{OBP} + \text{SLG}$
  - $\text{ISO} = \text{SLG} - \text{AVG}$（純長打率）
  - $\text{BABIP} = \frac{H - HR}{AB - K - HR}$（場內擊球安打率）
  - $\text{BB\%} = \frac{BB}{PA}$, $\text{K\%} = \frac{K}{PA}$, $\text{SB\%} = \frac{SB}{SB + CS}$

### 6.3 進階數據（`OPS+`, `wOBA`, `wRC+`, `RE24`, `WPA`）

1. **`OPS+`（標準化整體攻擊指數，聯盟平均 = 100）**：
   $$\text{OPS+} = 100 \times \left(\frac{\text{OBP}}{\text{lgOBP}} + \frac{\text{SLG}}{\text{lgSLG}} - 1\right)$$

2. **`wOBA`（加權上壘率）與 `wRC+`（加權得分創造值+，聯盟平均 = 100）**：
   - 線性權重（依場均 4.5 分環境校準）：
     $$\text{wOBA} = \frac{0.69 \cdot BB + 0.88 \cdot \text{1B} + 1.25 \cdot \text{2B} + 1.58 \cdot \text{3B} + 2.02 \cdot HR}{PA}$$
   - `wOBA Scale`：$\text{wOBAScale} = 1.25$
   - $\text{wRAA} = \frac{\text{wOBA} - \text{lgwOBA}}{\text{wOBAScale}} \times PA$
   - $\text{wRC+} = 100 \times \left(1 + \frac{\text{wRAA} / PA}{\text{lgR} / \text{lgPA}}\right)$

3. **`RE24`（24 種壘包出局狀態得分貢獻值）**：
   - 內建場均 4.5 分環境之 **24 狀態期望得分矩陣 $RE(\text{baseState}, \text{outs})$**（其中 $\text{baseState} \in [0..7]$ 對應壘包二進位遮罩，`outs` $\in \{0, 1, 2\}$，`outs = 3` 時 $RE = 0$）：
     | 壘包狀態 (二進位) | 0 出局 | 1 出局 | 2 出局 |
     | :--- | :---: | :---: | :---: |
     | **壘上無人 (`000`)** | 0.481 | 0.254 | 0.098 |
     | **一壘有人 (`001`)** | 0.859 | 0.509 | 0.224 |
     | **二壘有人 (`010`)** | 1.100 | 0.664 | 0.319 |
     | **一二壘有人 (`011`)** | 1.437 | 0.884 | 0.429 |
     | **三壘有人 (`100`)** | 1.350 | 0.950 | 0.353 |
     | **一三壘有人 (`101`)** | 1.784 | 1.130 | 0.478 |
     | **二三壘有人 (`110`)** | 1.964 | 1.376 | 0.580 |
     | **滿壘 (`111`)** | 2.292 | 1.541 | 0.736 |
   - 每次打席（或盜壘事件）之貢獻：
     $$\Delta \text{RE24} = (RE_{\text{after}} - RE_{\text{before}}) + \text{RunsScoredOnPlay}$$

4. **`WPA`（Win Probability Added，勝率貢獻值）**：
   - 透過解析式 + 查表混合之 **勝率期望函數 $WE(\text{inning}, \text{half}, \text{outs}, \text{baseState}, \text{scoreDiff})$**：
     - 根據當前局數與上下半局計算兩隊剩餘進攻半局數，結合當前半局剩餘期望得分 $RE(\text{baseState}, \text{outs})$ 與泊松/常態得分分布，即時算出主隊當下期望勝率 $WE \in [0, 1]$。
     - 每次打席結束後，進攻方勝率變化量 $\Delta WE = WE_{\text{after}} - WE_{\text{before}}$ 直接累加至該打者之 `WPA`（支援再見安打直接躍升至 $WE = 1.0$ 的高槓桿加成）。

5. **`WAR`（Wins Above Replacement，勝場貢獻值）**：
   - 嚴格遵循賽伯計量學（Sabermetrics）標準，將打擊創造得分、跑壘淨效益、雙殺打損益與替補球員基準水準整合為單一勝場指標：
     $$\text{WAR} = \frac{\text{wRAA} + \text{wSB} + \text{wGIDP} + \text{RepRuns}}{\text{RPW}}$$
   - 關鍵常數與組成分量定義：
     - **勝場得分轉換率（$\text{RPW}$）**：固定為 $10.0$ 分/勝（對應場均 4.4~4.5 分之 MLB 聯盟環境）。
     - **替補水準得分（$\text{RepRuns}$）**：比照 FanGraphs 標準，每 600 打席賦予 $20.0$ 分替補跑壘與打擊基底：
       $$\text{RepRuns} = \frac{20.0}{600} \times \text{PA}$$
     - **跑壘超越平均貢獻（$\text{wSB}$）**：
       $$\text{wSB} = (0.20 \times \text{SB} - 0.40 \times \text{CS}) - \text{lgStealRate} \times (\text{1B} + \text{BB})$$
     - **雙殺避免超越平均貢獻（$\text{wGIDP}$）**：
       $$\text{wGIDP} = (\text{lgGIDPRate} \times \text{AB} - \text{GIDP}) \times 0.45$$
   - 基準收斂驗證：
     - 全 50 基準打者因打擊與跑壘皆為聯盟平均，$\text{wRAA} \approx 0, \text{wSB} \approx 0, \text{wGIDP} \approx 0$。打滿 162 場全勤（約 688 打席）自然收斂至 **$2.29\text{ WAR}$**（完全落在合格全職打者 $[2.1, 2.5]$ 區間）。
     - 極端打者（如第一棒長打 100、單季 85 轟）$\text{wRAA} \approx +55$ 分，WAR 躍升至 **$8.0\text{ WAR}$**（淨增 $+5.5\text{ WAR}$）。

## 7. 系統技術架構與前端介面設計 (System Architecture & UI)

### 7.1 技術棧 (Tech Stack)
- **前端框架**：React 18/19 + TypeScript + Vite
- **樣式與視覺元件**：Tailwind CSS + Lucide Icons
- **背景高速運算**：Web Worker（獨立執行緒執行單季/多季模擬，透過 `postMessage` 即時回報每季完成進度與最終聚合報表，主執行緒 UI 保持 60fps 流暢）。
- **確定性虛擬亂數產生器（Seeded PRNG）**：實作 `Mulberry32` 快速 32-bit PRNG，支援使用者輸入固定 `Seed`（如 `2026`）以 100% 重現隨機序列，或選擇隨機 Seed。
